# 18 — Consolidar a spec de implementação

Type: task
Status: —
Blocked by: 06, 07, 08, 09, 10, 11, 12, 13, 14, 15, 16, 17

## Question

Reunir tudo o que o mapa decidiu num único documento que um agente consiga executar do zero, sem
precisar reler o mapa nem os tickets.

Não é uma decisão — é a montagem do destino. Puxa cada resolução, resolve as contradições que
aparecerem entre tickets fechados em sessões diferentes, e escreve a spec: stack e toolchain,
arquitetura e limites de módulo, schema do Dataset e como ele é gerado, pipeline de assets,
inventário de telas com o que cada uma faz, orçamento de performance com o método de medição, gates
de verificação, i18n, build e release.

A spec aponta para `CONTEXT.md` como glossário em vez de repetir definições. Sai com um plano de
implementação em fases, cada fase entregando algo executável e verificável.

Quando este ticket fecha, o mapa acaba e a construção começa fora dele.
