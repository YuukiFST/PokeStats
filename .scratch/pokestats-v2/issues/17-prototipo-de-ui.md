# 17 — Protótipo de UI no estilo Geist, validado pelo usuário

Type: prototype
Status: —
Blocked by: 03, 06, 12

## Question

O visual proposto é o que o usuário quer? Prosa não valida aparência — só um artefato clicável.

Usar a skill `prototype`. Construir um protótipo descartável, com dados falsos, cobrindo as
superfícies onde o estilo Geist é mais difícil e mais decisivo: a **tabela densa** de ranking (é a
tela principal e o ponto onde "elegante" e "muita linha na tela" brigam), a tela de detalhe de uma
Form com sprite e stat bars, e um card de Set com o botão Export.

Levar tema escuro e claro. Levar as duas variantes onde houver dúvida real de densidade, em vez de
escolher sozinho. Anexar o protótipo ao ticket como asset e registrar o que o usuário aprovou,
rejeitou e pediu diferente.

Decisão de saída: o vocabulário visual travado — tokens, altura de linha de tabela, tratamento de
hover e foco, e onde o sprite animado aparece.
